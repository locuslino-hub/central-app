# Central de Comando

Agenda pessoal com tarefas, calendário, e-mail (só leitura) e chat com IA local, no computador e no celular, com os mesmos dados. Instala pelo navegador, como aplicativo, e os dados ficam no Google Drive de quem usa.

Para conectar um aparelho, trocar o código de acesso ou restaurar uma cópia dos dados, veja o [GUIA.md](GUIA.md).
